`welcome.py` contains a `welcome()` function that creates greeting messages for different names.

`toolbox.py` contains three functions: `double()`, `is_pass()`, and `greet()` for practicing parameters, return values, and default parameters.

The `greet()` function was the hardest for me because it uses a default parameter. I had to understand how Python uses `"Hello"` automatically when no greeting is provided.
